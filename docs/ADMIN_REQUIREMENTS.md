# Admin Requirements

Административная панель MVP. **Один администратор — владелец проекта.** Роли и кабинет эксперта **не нужны**.

## Доступ

- Единственный admin-аккаунт (флаг в `profiles` или allowlist).
- Проверка прав **только на сервере**; URL админки не является защитой.

## Возможности администратора

### Материалы

- Создание, редактирование, публикация, скрытие.
- **Визуальный блочный редактор** контента.
- Статусы: черновик, опубликован, скрыт.
- Удаление навсегда — **только** если товар никто не покупал.
- Управление вложениями и обложками (медиа-библиотека).

### Разделы и обновления

- CRUD разделов; ручная цена.
- Формирование и публикация **обновлений раздела** с ценой.

### Задания

- CRUD заданий.
- Настройка списка критериев AI-проверки (без весов).
- Цена ручной проверки — **TBD** (поле в админке).

### Ручные проверки

- Очередь работ; в MVP проверяет **владелец**.
- Черновик результата, превью для пользователя, публикация.
- Редактирование опубликованной проверки с сохранением версий.
- Запрос доработки (1 повторная отправка у пользователя).

### Пользователи

- Просмотр профилей.
- Ручная выдача и отзыв доступа.
- Деактивация по запросу поддержки.

### Заказы и платежи

- Просмотр заказов и платежей.
- Обработка **ошибок выдачи доступа** после подтверждённой оплаты.
- Экспорт пользователей, заказов, продаж в **CSV**.

### Отзывы

- Скрытие отзывов (публикация по умолчанию сразу).

### Главная и медиа

- Редактирование главной страницы (каталог).
- Медиа-библиотека (Storage assets).

### Возвраты

- Ручная обработка запросов с поддержки (REF-01–REF-05).

## Дашборд главной админки

- Выручка
- Заказы
- Пользователи
- Продажи по товарам
- Задания на проверке (очередь)
- Популярные материалы
- Конверсия
- Ошибки оплат / выдачи доступа

Бизнес-аналитика хранится и показывается **в админке** (см. `ANALYTICS.md`).

## Вне MVP

- История изменений материалов, заказов и цен
- Несколько ролей и прав
- Отдельный кабинет эксперта
- Автоматический workflow возвратов
