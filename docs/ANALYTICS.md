# Analytics

## Два уровня

1. **Бизнес-аналитика** — хранится и отображается **в админке** (дашборд).
2. **Внешняя аналитика** — **Яндекс Метрика** + **Вебвизор**.

## Яндекс Метрика

- Подключение **только после** согласия в cookie-баннере (этап 18).
- Ecommerce: purchase — **после серверного подтверждения оплаты**, не на success URL.

### События для отслеживания

| Категория | События |
|-----------|---------|
| Auth | Регистрация |
| Каталог | Просмотры, поиск, фильтры |
| Корзина | Добавление, изменение |
| Checkout | Начало оформления |
| Заказы | Бесплатные получения (0 ₽) |
| Оплата | Успешные и неуспешные |
| Покупки | По товарам (material / assignment / section) |
| Отзывы | Создание отзыва |
| Задания | Отправки решений |
| Проверки | AI-проверки, ручные проверки |

Точные имена целей и payload ecommerce — по документации Метрики на **этапе 17**.

## Админ-дашборд (внутренняя аналитика)

Метрики на главной админки (`ADMIN_REQUIREMENTS.md`):

- Выручка
- Заказы
- Пользователи
- Продажи по товарам
- Задания на проверке
- Популярные материалы
- Конверсия
- Ошибки оплат

Данные агрегируются из PostgreSQL (этапы 15, 17).

## Env

- `NEXT_PUBLIC_YANDEX_METRICA_ID`

## Cookie consent

- Метрика и Вебвизор не загружаются до согласия.
- Тексты баннера — в рамках юридических страниц (**юридические тексты TBD**).

## Не отслеживается в MVP

- Прогресс прохождения материалов
- Чек-ины, стрики
