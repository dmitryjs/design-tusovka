# MVP Scope

## Цель MVP

Русскоязычная платформа «Дизайн Тусовка» с полным циклом: каталог (главная) → корзина → заказ (0 ₽ или оплата) → библиотека → задания → AI/ручная проверка → отзывы; админка, уведомления, аналитика, поддержка, юридические страницы.

## Товары MVP

| Товар | Описание |
|-------|----------|
| Материал | 8 типов; главы на одной странице; бесплатный или платный |
| Задание | Отдельный товар; не в разделе |
| Раздел | Категория + набор материалов; обновления раздела |

## Явно вне MVP

- Подписки, промокоды, избранное
- Прогресс обучения, чек-ины, стрики
- Роли админов и кабинет эксперта (только владелец)
- История изменений материалов, заказов и цен
- Автоматический интерфейс возвратов
- Мобильное нативное приложение

## Утверждённые ограничения

- Стек: Next.js App Router, React, TypeScript strict, Tailwind, shadcn/ui, Supabase, PostgreSQL, Vercel, GitHub.
- Git инициализировать **перед этапом 2**.
- Файлы: **Supabase Storage** (публичные и приватные bucket).
- Авторизация: email+пароль, Google OAuth, восстановление пароля.
- Email подтверждён до оплаты и отправки решения.
- Один email — один аккаунт.
- Доступ бессрочный после покупки/бесплатного заказа (где применимо).
- Цены в рублях; задаются вручную администратором.
- Оплата: ЮKassa, СБП QR, крипто с авто-подтверждением.
- Доступ только после серверного подтверждения оплаты/webhook.
- Платежи: ИП на УСН «Доходы»; чеки через решение ЮKassa для 54-ФЗ (конфигурация — по документации на этапе 10).
